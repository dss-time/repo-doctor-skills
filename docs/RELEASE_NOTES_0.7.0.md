## Easier installation and use

The default entry remains `npx repo-doctor-skills install` (Recommended 7/7). Full remains 40/40. Reinstalling skips identical content; expanding Recommended to Full adds missing Skills. Different local content requires explicit `--force` replacement.

Use `--skill safe-code-review` for one Skill, or `--language en` / `--language zh-CN` for one body language. Bilingual remains the default and every supporting resource is retained. Unknown, repeated and incomplete options are rejected.

Onboarding now starts with installation and one useful request. Repeated quick-entry guides point to one problem-to-Skill guide. Common Skills default to conclusions and decisive evidence, omitting empty fields; detailed evidence and command ledgers remain available. Authorized workflows may continue within each Skill's permissions; Router remains recommendation-only.

Project version is 0.7.0; Repo Doctor Pack/plugin is 0.9.0. Public slugs, permission metadata, specialist boundaries and component maturity are preserved. skills.sh retains 40/40 discovery with zero YAML errors or fixtures. The release asset contract remains 37 standalone ZIPs, RELEASE_NOTES, RELEASE_MANIFEST and SHA256SUMS.
