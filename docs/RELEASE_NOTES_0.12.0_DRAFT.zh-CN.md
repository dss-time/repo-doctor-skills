# Repo Doctor 0.12.0 发布草案

[English](RELEASE_NOTES_0.12.0_DRAFT.md)

**发布判定为 NO-GO。** 包元数据与稳定版安装指引仍指向 0.11.1。

## 改动

- Change Guard 将 Git 可见的修改与工作树绑定的私有基线比较，报告已有改动被触及、范围偏移、受保护路径和未知覆盖。
- 本地验证修复了模式与类型的重复提示、符号链接路径影响其他覆盖，以及大小写不敏感文件系统中的范围和保护路径别名。
- 功能实现、安全修复、安全测试和文档同步共享内置 Guard 入口，在风险、授权和宿主能力允许时可自动调用。运行时不可用时，保留未知覆盖并继续人工检查。
- 验证凭据绑定工作树。旧凭据仍可读取，复用前需要重新观测。

## 兼容性和限制

仓库、npm 包、命令、插件和 Skills 保留既有标识。Guard 运行时由源码 CLI、本地 npm 包、上述单装 Skills 和 Codex Plugin 提供。报告保留未知来源，项目代码和 Git 索引保持原状。忽略路径、隐藏索引项、子模块内部修改及短暂并发变更可能遗漏。

## 发布门禁

本地内容冻结使用候选指纹，稳定版 npm 元数据仍为 0.11.1。macOS 上 Node 18 和 24 构建产物一致，已发布的 0.11.1 npm 包可升级到候选。正式门禁拒绝旧版绑定证据，开发一致性检查通过。Linux 与 Windows 仍待实际运行。 [冻结记录与构建证据](research/change-guard-integration.md#候选冻结和本轮补验)

## 试用范围

本地 macOS **GO**。四个适用的最终候选样本中三个完成自动基线与检查。公共模块任务漏触发，低风险任务保持轻量。新增三案复测受同一模型的额度限制，报告处理仍需补证。公开 Beta **BLOCKED**，待设定独立预发布版本、在授权范围内验证对应产物与安全要求。RC **BLOCKED**，还缺当前候选的 Linux 和 Windows 运行及发布绑定证据。Stable **NO-GO**，现有正式门禁未通过。宿主 Hook 仍未经实跑。 [实测与边界](research/change-guard-integration.md)
