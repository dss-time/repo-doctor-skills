# Repo Doctor

**Make AI coding safer, not slower.**

Safe, scoped, and verifiable code changes for AI coding agents.

Repo Doctor complements the coding agent and Skills a developer already uses. Its job is to make the intended change reviewable, surface unrelated or concurrent edits, and show which checks support delivery. The existing bilingual Skills remain independently usable.

A clear local task can use one Skill and one focused check. When a dirty worktree or wider scope needs a baseline, Change Guard reports Git-visible differences without changing the project or staging area. For material risks, trace callers and choose verification that exercises actual contracts, permissions or data behavior. Reuse existing execution evidence only while its inputs and live attestations support it.

The public identifiers `dss-time/repo-doctor-skills`, `repo-doctor-skills` and the current Skill and plugin IDs preserve existing installations. Git-based reports are advisory. Tool permissions, change attribution and runtime verification remain host responsibilities.

The [upgrade audit and evaluation plan](research/change-safety-upgrade.md) records repository evidence, known limits and the comparative experiment design.
