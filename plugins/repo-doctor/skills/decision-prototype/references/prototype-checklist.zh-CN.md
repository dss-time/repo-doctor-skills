# 决策原型详细检查表

只在设计分支或准备 audit 证据时读取。

## 逻辑原型

- 只有一个状态或业务规则问题
- 覆盖决策关键边界的合成输入
- 可见的前态、动作和后态
- 复用现有运行时的一条可执行命令
- 除非单独批准非生产环境，否则不持久化、不发送外部请求

## UI 原型

- 只有一个交互或信息结构问题
- 需要比较时才提供两个或更多结构明显不同的方向
- 使用代表性合成状态；适用时包含空、错误和高密度状态
- 复用现有设计体系和运行时，不执行生产写操作
- 提供直接选择和比较方向的方法

## audit 证据

- 已授权路径与命令
- 命令预检、工作目录、退出码和结果
- 生产隔离与脱敏检查
- 判据到观察结果的映射
- 结论、不确定性、处置建议和生产交接
