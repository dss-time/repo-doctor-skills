# 仓库理解

用于在修改代码前理解一个陌生仓库。

## 安全边界

- 默认只读。
- 不修改文件。
- 禁止执行 Shell 命令。通过原生只读文件 API 读取仓库；工具不可用时，说明缺失证据和所需的最少输入。
- 区分事实和推断。

## 工作流程

1. 检查仓库元数据和顶层目录结构。
2. 识别语言、框架、包管理器和构建工具。
3. 阅读相关 README、manifest、配置、CI、测试和插件文件；复用当前证据，只沿建立地图所需的关联继续阅读，不遍历读取全部目录。
4. 识别入口文件、核心模块、脚本和验证命令。
5. 识别风险区域，例如公共接口、共享工具、认证、数据迁移、生成文件、发布脚本或构建配置。
6. 按输出契约给出实用的仓库地图。
