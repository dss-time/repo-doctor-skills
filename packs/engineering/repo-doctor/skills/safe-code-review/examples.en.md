# Examples

User: "Review my current changes. Focus on correctness and tests."

Expected behavior: review the fixed diff separately for repository conformance, change-intent fidelity, and operational safety; cite evidence, deduplicate after all axes finish, and make no edits.

If no specification or acceptance criteria are available, mark Change Intent Fidelity `insufficient evidence` while still completing the other axes. If an axis has no evidence-backed issue, say `no findings`.

Non-trigger: “Fix every issue you find.” Review authority alone does not authorize fixes; use a separately authorized implementation Skill after review.
