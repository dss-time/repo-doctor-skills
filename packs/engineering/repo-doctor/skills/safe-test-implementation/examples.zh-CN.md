# 示例

- `test_first`：“保护锁定账户拒绝登录的行为。”确认公共边界，只补一个测试，证明它因该行为缺失而失败，再等待独立授权的生产实施。
- `regression_after_fix`：“会话修复已经验证，请补回归测试。”在修复后状态运行并报告安全敏感性证据，不编造历史红灯。
- `characterization`：“重构前保留当前 CSV 转义契约。”初次通过有效，但断言必须能区分有意义状态。
- audit 阻塞：测试脚本包含依赖安装或数据库迁移。将命令记录为 `Blocked`，不得执行。
- 反例：“修复生产代码中的空指针。”应使用 `safe-fix-implementation`。
