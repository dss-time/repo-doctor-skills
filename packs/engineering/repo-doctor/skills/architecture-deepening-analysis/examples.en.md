# Examples

- “Three callers each translate the same domain state into the same transport shape, and changes touch all three. Analyze deeper module options without refactoring.” Trace callers, compare at least two directions, and preserve compatibility/rollback.
- “This file is 2,000 lines; split it into cleaner modules.” File size alone is insufficient. Return no qualified candidate unless caller, responsibility, change, or test evidence establishes friction.
- “Rewrite the entire subsystem now.” Do not execute. Route through clarification, impact analysis, planning, and explicit write authorization.

Non-trigger: “Record our already selected architecture decision.” Use `architecture-decision-record`.
