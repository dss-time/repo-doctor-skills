# Examples

- “Choose the execution mode and implement these two approved independent slices.” Inspect dependencies and isolation. Use multi only with useful independent work and declared worker limits and verifiable activity; integrate and validate actual results.
- “Use multi-agent-workflow to fix this exact one-line null check.” Choose single with safe-fix-implementation and finish the authorized repair.
- “Use independent read-only agents to review the approved diff.” Load safe-code-review, assign fixed-baseline axes, constrain writes/Shell/network and disclose host enforcement limits, then verify and deduplicate findings.
- “Implement in parallel, but this host has no subagents or isolated workspaces.” Report capability limits and use single if allowed; a required independent-agent acceptance condition remains blocked.
- “Use safe-code-review on this small diff.” Keep that direct Skill as owner. The coordinator should not activate merely because other Skills are installed.
