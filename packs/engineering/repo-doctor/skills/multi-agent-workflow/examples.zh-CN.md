# 示例

- “自动选执行模式，实施两个已批准且独立的功能切片。”核对依赖和隔离，只有实际独立且可声明子任务限制并核验活动时 multi，集成后真实验证。
- “用 multi-agent-workflow 修复这一行空值判断。”选择 single 与 safe-fix-implementation，完成已授权修复。
- “用独立只读 Agent 审查这个已确认 diff。”加载 safe-code-review，按固定基线分配维度，限制写入/Shell/网络并披露宿主强制控制局限，再核验汇总。
- “并行实现，但宿主没有子 Agent 或隔离工作区。”说明能力限制，允许时回退 single；必需独立 Agent 的验收条件仍阻塞。
- “使用 safe-code-review 审查这个小 diff。”保留直接指定的主 Skill，不因安装了更多 Skill 就启动协调入口。
